
# Paradise Nursery - Plant Shopping Application

Paradise Nursery is an online plant shopping application built using React and Redux.

Users can browse different categories of plants, add plants to their shopping cart, update quantities, remove products, and view their cart total.

## Technologies Used
- React.js
- JavaScript
- Redux Toolkit
- React Redux
- CSS

## Project Features
- Plant categories
- Product listing
- Add to Cart
- Shopping cart management
- Quantity updates
- Cart total calculation
