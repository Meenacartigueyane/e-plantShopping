

# Paradise Nursery – Online Plant Shopping Application

Paradise Nursery is an online plant shopping application built using React and Redux Toolkit. It allows users to explore different plants and manage their shopping cart.

## Features

- Browse plants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- Calculate the total quantity and total cost.
- Continue shopping.

## Technologies Used

- React.js
- Redux Toolkit
- JavaScript
- HTML
- CSS

## Project Components

- `App.jsx` – Main application component.
- `ProductList.jsx` – Displays plant products.
- `CartItem.jsx` – Manages shopping cart items.
- `CartSlice.jsx` – Manages cart state using Redux Toolkit.
- `store.js` – Configures the Redux store.
- `App.css` – Application styling.

## How to Run

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the application:

   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal.

## Project Description

This project demonstrates a simple online plant shopping experience with product browsing and shopping cart management using React and Redux Toolkit.
